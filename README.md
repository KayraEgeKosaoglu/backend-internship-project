# Backend Internship Project

## Project Purpose
Learning backend development, microservices,
asynchronous communication and containerization.

## Technologies
- Python
- FastAPI
- PostgreSQL
- MongoDB
- RabbitMQ
- Apache Kafka
- Docker
- Docker Compose
- gRPC
- Git and GitHub
- ## Learning Progress
- Development environment setup completed.
- Git and GitHub configuration completed.
## REST API Implementation

- FastAPI and Uvicorn integration
- Order creation and listing
- Order retrieval by ID
- Order update using PUT
- Order status update using PATCH
- Order deletion
- Request data validation with Pydantic
- HTTP error handling
- Swagger UI testing

Currently, order data is stored in memory.
PostgreSQL integration will be implemented in the next stage.
